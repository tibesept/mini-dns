# Веб-приложение "Mini-DNS" (Дипломный проект)

Данный проект представляет собой практическую часть дипломной работы: полноценный прототип интернет-магазина компьютерных комплектующих и периферии (аналог DNS). Проект спроектирован с упором на чистый нативный PHP (без тяжелых фреймворков), что идеально подходит для демонстрации навыков backend-разработки, работы с базами данных и понимания паттерна MVC.

## 1. О проекте
"Mini-DNS" — это интернет-магазин, позволяющий пользователям:
- Просматривать каталог товаров с фильтрацией по категориям и сортировкой.
- Читать карточки товаров и оставлять отзывы.
- Добавлять товары в корзину (реализовано через AJAX и сессии PHP, без перезагрузки страниц).
- Оформлять заказы через модальное окно.

Для администратора предусмотрена **Админ-панель**, в которой можно:
- Авторизовываться безопасно (с хэшированием пароля).
- Просматривать сводку по заказам.
- Одобрять или удалять новые отзывы пользователей.

**Стек технологий:**
- **Backend:** Нативный PHP 8+, PDO (защита от SQL-инъекций).
- **База данных:** MySQL 8.
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Bootstrap 5.
- **Инфраструктура:** Docker, docker-compose.

## 2. Как это работает

Приложение имеет архитектуру, максимально приближенную к MVC (Model-View-Controller). 

### Структура папок
* `config/` — конфигурация. Здесь лежит `db.php`, отвечающий за создание PDO-соединения с БД.
* `models/` — классы, инкапсулирующие работу с таблицами БД. Например, `Product.php` умеет получать товары, а `User.php` проверяет пароли.
* `views/` — HTML-шаблоны.
  * `views/layout/` — `header.php` и `footer.php` (общие части сайта).
  * `views/admin/` — шаблоны для админ-панели (`login.php`, `dashboard.php`, `reviews.php`).
* `public/` — статика сайта.
  * `public/css/style.css` — кастомные стили (цвета, анимации, тени).
  * `public/js/main.js` — логика корзины и отправка AJAX-запросов.
  * `public/uploads/` — картинки товаров.
* **Корневые файлы (Контроллеры):**
  * `index.php`, `catalog.php`, `product.php` — отвечают за клиентские страницы. Они подключают Модели, получают данные и передают их в шаблоны.
  * `cart_api.php`, `checkout.php` — API-эндпоинты (принимают POST-запросы из JS и возвращают JSON).
  * `admin.php` — единый роутер для админ-панели (переключает логику по `$_GET['action']`).

### Запуск проекта (Docker)
Для запуска нужен установленный Docker Desktop:
```bash
# 1. Запустить контейнеры (PHP, MySQL, PhpMyAdmin)
docker-compose up -d --build
```
При первом запуске MySQL автоматически прочитает скрипт `init.sql` и создаст таблицы с тестовыми данными. Любые изменения в коде PHP применяются **мгновенно** (благодаря пробросу volume `.:/var/www/html` в `docker-compose.yml`).

- **Сайт:** `http://localhost:8080`
- **PhpMyAdmin:** `http://localhost:8081` (Логин: `root`, Пароль: `root_password`)
- **Админка:** `http://localhost:8080/admin.php` (Логин: `admin`, Пароль: `admin123`)

## 3. Как модернизировать проект (Инструкция по расширению)

Проект легко масштабируется. Ниже приведены инструкции по добавлению новых функций.

### Добавление CRUD для Товаров в админ-панели
Сейчас в админке есть "скелет", но нет интерфейса добавления новых товаров (CRUD). Чтобы его добавить:
1. **В роутере (`admin.php`):**
   Добавьте новый `case 'products':` в `switch ($action)`.
   Там вызовите метод `$productModel->getAll()`.
2. **В шаблонах (`views/admin/`):**
   Создайте файл `products.php` (по аналогии с `reviews.php`), где выведите таблицу с товарами и кнопку "Добавить товар".
3. **Обработка формы:**
   Добавьте `case 'product_add':` в `admin.php`. Внутри напишите логику получения данных из `$_POST`, загрузки картинки из `$_FILES['image']` в папку `public/uploads/` и вызовите метод `$productModel->add(...)`.
4. **В модели (`models/Product.php`):**
   Напишите метод `public function add($categoryId, $name, $desc, $price, $image)`. Внутри выполните `INSERT INTO products ...` через `$this->pdo->prepare(...)`.

### Редактирование стилей
Если вы хотите изменить цвета или анимации:
1. Откройте `public/css/style.css`.
2. В самом начале файла есть блок `:root`. Измените `--accent-color` (например, на красный `#d90429`), чтобы поменять главный цвет сайта.
3. Обновите страницу в браузере (нажмите `Ctrl + F5` или `Cmd + Shift + R`, чтобы сбросить кэш стилей).

### Изменение логики базы данных
Если вам нужно добавить новое поле (например, "Старая цена"):
1. Добавьте его в `init.sql` (чтобы при переустановке проекта оно сохранялось).
   ```sql
   ALTER TABLE `products` ADD `old_price` DECIMAL(10,2) NULL AFTER `price`;
   ```
2. Если вы хотите применить это к *уже работающей* базе, зайдите в PhpMyAdmin (`http://localhost:8081`) и выполните SQL-запрос там, либо полностью удалите контейнеры с их "томами" (`docker-compose down -v`) и поднимите заново.
3. Обновите класс `Product.php` и HTML-файлы (например, `index.php`), чтобы выводить `$product['old_price']`.

### Добавление новых страниц (например, "О нас")
1. Создайте в корне файл `about.php`.
2. В начале файла подключите конфигурацию:
   ```php
   <?php require_once 'config/db.php'; ?>
   ```
3. Подключите "шапку": `<?php include 'views/layout/header.php'; ?>`
4. Напишите свой HTML код.
5. Подключите "подвал": `<?php include 'views/layout/footer.php'; ?>`
6. В файле `views/layout/header.php` найдите блок `<ul class="navbar-nav">` и добавьте туда ссылку на `about.php`.
